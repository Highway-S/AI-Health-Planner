AI Personalized Health & Fitness Planner

ระบบดูแลสุขภาพเฉพาะบุคคลด้วยปัญญาประดิษฐ์ (AI)

รายวิชา: ปัญญาประดิษฐ์ (Artificial Intelligence)
สมาชิก: 4 คน (กลุ่มโครงงาน AI)

1. การตั้งโจทย์ปัญหา (Problem Statement)

ในปัจจุบัน ปัญหาด้านสุขภาพจากการดำเนินชีวิต (Lifestyle Diseases) เช่น โรคอ้วน เบาหวาน และความดันโลหิตสูง กำลังทวีความรุนแรงมากขึ้น การวางแผนโภชนาการและการออกกำลังกายที่ถูกต้องจำเป็นต้องอาศัยผู้เชี่ยวชาญ (Personal Trainer หรือนักกำหนดอาหาร) ซึ่งมีค่าบริการสูงและไม่สามารถเข้าถึงได้ทุกคน ข้อมูลบนอินเทอร์เน็ตส่วนใหญ่เป็นคำแนะนำทั่วไป ไม่ได้ปรับให้ตรงกับสรีระ เป้าหมาย ข้อจำกัดอาหาร หรืออุปกรณ์ที่มีของผู้ใช้

โจทย์หลักของโครงงาน: พัฒนาระบบ AI ที่สามารถวิเคราะห์ข้อมูลสุขภาพส่วนบุคคล คำนวณพลังงานที่แม่นยำ และจัดสร้างแผนอาหารไทยและตารางออกกำลังกายแบบเฉพาะบุคคล พร้อมระบบติดตามผลและแชทให้คำปรึกษาได้อย่างมีประสิทธิภาพและปลอดภัย

2. กระบวนการเตรียมข้อมูล (Data Preparation)

  • ข้อมูลผู้ใช้ (User Input Profile): อายุ, เพศ, ส่วนสูง, น้ำหนัก, น้ำหนักเป้าหมาย, ระยะเวลา, ระดับกิจกรรม, ข้อจำกัดอาหาร, อาหารที่แพ้, อุปกรณ์ออกกำลังกาย
  • ฐานข้อมูลอาหารไทย (Thai Food Nutrition Dataset): รวบรวมข้อมูลโภชนาการอาหารไทยกว่า 80+ รายการ พร้อมค่าแคลอรี, โปรตีน, คาร์โบไฮเดรต, ไขมัน, ขนาดบริโภค และสารก่อภูมิแพ้
  • ฐานข้อมูลการออกกำลังกาย (Workout Dataset): รวบรวมท่าออกกำลังกายกว่า 60+ ท่า จำแนกตามอุปกรณ์ (Bodyweight, Dumbbell, Barbell, Machine) ระดับความยาก และอัตราการเผาผลาญ
  • ข้อมูลสังเคราะห์ (Synthetic Dataset for ML): สร้างข้อมูลสถิติสุขภาพ 1,000 ตัวอย่าง ตามหลักการ Mifflin-St Jeor และ Harris-Benedict สำหรับฝึกสอนโมเดล Machine Learning
  • การจัดเก็บข้อมูล: ใช้ฐานข้อมูล SQLite จัดการโครงสร้างตารางผู้ใช้ ประวัติสุขภาพ เมนูอาหาร และตารางฝึก

3. ภาพรวมของโมเดลที่ได้ทำการทดลอง (Model Overview)

โมเดล หลักการทำงาน จุดเด่น จุดด้อย
1. Rule-Based System สูตรคำนวณทางการแพทย์ Mifflin-St Jeor & TDEE Multipliers แม่นยำสูง อิงหลักสรีรวิทยาที่ได้รับการยอมรับ ไม่ยืดหยุ่น ปรับตามรูปแบบซับซ้อนไม่ได้
2. Random Forest Regressor Supervised ML ฝึกสอนจากข้อมูล 1,000 ตัวอย่าง ทำนายแคลอรีเป้าหมาย เรียนรู้ความสัมพันธ์ของตัวแปรหลายมิติได้ดี ขึ้นกับขอบเขตข้อมูลที่ฝึกสอน
3. Hybrid AI System (โมเดลที่เลือก) ผสาน Medical Formulas + Random Forest Validation + Template NLG Logic คำนวณแม่นยำ มีการตรวจสอบความถูกต้อง และสร้างคำแนะนำภาษาธรรมชาติเฉพาะบุคคล โครงสร้างระบบมีความซับซ้อนกว่า

4. ประสิทธิภาพของโมเดลสุดท้ายและเหตุผลในการตัดสินใจ

ตัวชี้วัดประสิทธิภาพ ผลลัพธ์ เกณฑ์มาตรฐาน
Machine Learning R² Score 0.92 - 0.95+ > 0.85 (ระดับดีเยี่ยม)
ความคลาดเคลื่อน Meal Plan vs Target Calories ±3% ถึง ±5% ≤ 10% (ตามเป้าหมายโภชนาการ)
Personalization Accuracy (Workout & Food Filter) 100% ตามข้อจำกัด/อุปกรณ์ กรองสารก่อภูมิแพ้และอุปกรณ์ครบถ้วน

เหตุผลในการตัดสินใจ: สุขภาพเป็นเรื่องที่ต้องการความปลอดภัยสูง Hybrid AI System จึงเป็นตัวเลือกที่เหมาะสมที่สุด เพราะใช้สูตรทางการแพทย์ที่ได้รับการพิสูจน์แล้วในการควบคุมปริมาณ Deficit/Surplus แคลอรีไม่ให้เกิดอันตราย พร้อมใช้ NLG ในการปรับภาษาและคำแนะนำให้เข้ากับผู้ใช้รายคน

5. แนวทางการนำไปใช้งานจริง (Deployment Architecture)

[User Input] → [Health Data Processing] → [BMI/BMR/TDEE Calculation] ↓ [AI Personal Analysis & Constraints Filter] ↓ +-----------------------+-------------------------+ | Meal Plan Generation | Workout Plan Generation | +-----------------------+-------------------------+ ↓ [Personalized Dashboard & Interactive AI Assistant] ↓ [Progress Tracking & Weekly AI Plan Adjustment]
  • Backend: Python / Flask Framework พร้อม SQLite Database
  • Frontend: Responsive Modern Health-Tech Web Application (HTML5, CSS3, JavaScript, Chart.js)
  • กลุ่มผู้ใช้งาน: บุคคลทั่วไปที่ต้องการดูแลสุขภาพ, ผู้เริ่มต้นลดน้ำหนัก/สร้างกล้ามเนื้อ, พนักงานออฟฟิศ

6. ความท้าทายที่พบและแนวทางปรับปรุงในอนาคต

  • ความท้าทาย: ความหลากหลายของส่วนผสมอาหารไทยที่อาจมีปริมาณเครื่องปรุงไม่เท่ากันในแต่ละร้าน
  • แนวทางพัฒนาต่อ: เชื่อมต่อ Large Language Model (LLM API เช่น Gemini) สำหรับการสนทนาสุขภาพที่ซับซ้อนขึ้น, พัฒนาระบบ Computer Vision สำหรับตรวจจับอาหารจากภาพถ่าย (Food Recognition), และเชื่อมต่อข้อมูลจาก Smart Watch (Apple Health / Google Fit)
